# 03: Focus the editor on the timeline workflow

**What to build:** Make the full-video timeline the central seek control, identify the preview as an absolute source window, order marker actions as Set start, Set end, Add segment, and keep the selectable/removable segment list visible.

**Blocked by:** 01

**Category:** enhancement
**Status:** ready

- [ ] Preview range, absolute playhead, and full duration use one consistent time format.
- [ ] The preview does not expose a second prominent seek bar.
- [ ] Filmstrip thumbnails are readable and include visible time references.
- [ ] Add segment is disabled for invalid or empty markers and visibly explains why.
- [ ] Segment rows expose label, duration, selection state, and remove action; selection highlights the timeline range.
- [ ] Frame stepping, playback, markers, undo, and redo retain documented keyboard access.
