# Stage 1 — Neutral Server Networking Configuration

**State:** TERRA_AGENTS_SPAWNED

## Frozen contract

- `EDITAPP_LISTEN_ADDRESS` is an IP literal and defaults to `127.0.0.1`.
- `EDITAPP_PORT` is an integer from 1 through 65535 and defaults to `8787`.
- The effective address is built with `net.JoinHostPort`.
- Explicit `0.0.0.0` and IPv6 bindings are allowed in production mode.
- Development authentication remains loopback-only until Stage 4.
- `EDITAPP_PUBLIC_BASE_URL` is optional; when set it is an absolute HTTP(S)
  URL without userinfo, query, or fragment.
- `EDITAPP_ALLOWED_ORIGINS` is an optional comma-separated exact-origin list;
  each entry is HTTP(S) scheme plus host and optional port, with no credentials,
  path, query, or fragment. Stage 1 only parses it; CORS behavior begins in
  Stage 3.
- `EDITAPP_TRUSTED_PROXY_CIDRS` keeps its existing generic CIDR contract.
- `EDITAPP_READ_TIMEOUT`, `EDITAPP_WRITE_TIMEOUT`, and
  `EDITAPP_IDLE_TIMEOUT` use Go duration syntax. Defaults are `15s`, `0s`, and
  `60s`; read and idle must be positive, write may be zero for streaming.
- `EDITAPP_LISTEN_ADDR` remains a legacy alias only when neither new listener
  setting is present. Mixing legacy and new settings fails as ambiguous.
- `cmd/server` exposes an unexported `newHTTPServer` construction seam for
  timeout/address tests; it does not add a public abstraction.

## Acceptance criteria

1. Listener startup contains no connectivity-provider dependency.
2. Default binding remains `127.0.0.1:8787`; explicit LAN binding works.
3. Invalid IPs, ports, URLs, origins, CIDRs, durations, ambiguous legacy
   settings, and non-loopback development mode fail before server startup.
4. The effective joined listener is logged and used by `http.Server`.
5. Read, write, and idle timeouts are wired exactly from configuration.
6. Existing preview/authentication behavior otherwise remains unchanged.
7. Loopback, non-loopback, IPv6, legacy, validation, and actual bind tests pass.
8. No deployment files or unrelated packages change in Stage 1.
