## Frozen contract

```ts
type ClientConfiguration = {
  serverBaseUrl: string;
  authentication:
    | { type: "none" }
    | { type: "bearer"; token: string }
    | { type: "cookie" };
};
```

- A runtime `window.EDITAPP_CONFIG` may provide the configuration before the
  application module loads. The fallback is the current page origin with
  `{type: "none"}`.
- `serverBaseUrl` must be an absolute HTTP(S) URL without credentials, query,
  or fragment. A path prefix is allowed. Trailing slash variants normalize to
  one base, then `/api/v1/` is appended beneath it.
- API request paths are relative to that API base. Absolute, scheme-relative,
  fragment-bearing, or parent-escaping paths are rejected.
- One `createApiClient` boundary exposes URL construction and request methods.
  Every application request, including preview streaming, uses it.
- `none` removes authorization and omits credentials; `bearer` validates a
  non-empty control-character-free token, sets `Authorization: Bearer ...`,
  and omits credentials; `cookie` removes authorization and includes
  credentials.
- Caller headers are preserved except for the centrally owned authorization
  policy.
- `streamPreview` receives a request callback rather than calling global
  `fetch`, preserving streaming and `AbortController` cancellation.
- No server CORS behavior changes in Stage 2.

## Acceptance criteria

1. No hardcoded hostname, tailnet domain, or mandatory same-origin request.
2. All App and preview network calls route through the client boundary.
3. Trailing slashes, path prefixes, encoded IDs, and query strings build safe
   URLs without escaping `/api/v1/`.
4. None, bearer, and cookie policies behave exactly as frozen.
5. The four required example server URLs are accepted.
6. Cross-origin browser tests prove metadata, preview streaming, and stale
   cancellation against a separately configured origin.
7. Existing accessibility, project, preview-offset, and conflict behavior pass.
8. No dependency, server behavior, or unrelated frontend change is introduced.
